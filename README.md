# Домашнє завдання: Практичне застосування оптимізації та рандомізованих алгоритмів

Цей репозиторій містить розв'язання двох практичних завдань: дослідження ефективності касових алгоритмів (жадібний та динамічний підходи) та обчислення визначеного інтеграла методом Монте-Карло з аналітичною верифікацією.

---

## Завдання 1: Оптимальний спосіб видачі решти

Було реалізовано два підходи для канонічного набору монет `[50, 25, 10, 5, 2, 1]`:

1. **Жадібний алгоритм (`find_coins_greedy`)**: Працює за константний час $O(1)$ (або $O(N)$ відносно кількості номіналів), використовуються базові арифметичні операції. На великих сумах (наприклад, 1 000 000) працює миттєво.
2. **Динамічне програмування (`find_min_coins`)**: Має складність $O(M \times N)$, де $M$ — сума решти. При великих сумах лінійно зростають як час виконання, так і витрати оперативної пам'яті під збереження масивів проміжних станів (Bottom-Up).

**Висновок**: Для стандартних грошових систем **жадібний алгоритм є безумовним фаворитом**, оскільки він працює набагато швидше і не споживає додаткових ресурсів пам'яті. Динамічне програмування є доцільним лише для нестандартних (неканонічних) наборів монет, де жадібний вибір не може гарантувати глобальний оптимум.

## Завдання 2: Обчислення інтеграла методом Монте-Карло

Реалізовано алгоритм обчислення площі під кривою функції $f(x) = x^2$ на проміжку $[0, 2]$ шляхом випадкового моделювання точок у прямокутній системі координат (геометрична ймовірність).

### Результати тестування (симуляція на 500 000 точок):

- **Метод Монте-Карло**: `2.668128` (значення змінюється в межах похибки при кожному запуску)
- **Аналітичний розрахунок (`scipy.integrate.quad`)**: `2.666667`
- **Абсолютна похибка**: `~0.001461`

### Висновки щодо точності методу:

1. **Залежність від кількості експериментів**: Точність методу Монте-Карло безпосередньо залежить від кількості згенерованих точок ($N$). При малих $N$ похибка є помітною, але при збільшенні кількості точок до 500 000 і більше результат стабільно наближається до точного інтеграла ($2.666...$).
2. **Ефективність**: Метод Монте-Карло не забезпечує абсолютної математичної точності порівняно з аналітичним інтегруванням (`quad`), яке використовує адаптивні квадратурні формули та працює значно швидше.
3. **Область застосування**: Попри високі обчислювальні витрати, рандомізований метод Монте-Карло є незамінним у складних інженерних задачах, де аналітичне взяття інтеграла є неможливим, або для прорахунку площ багатовимірних фігур зі складними межами обмеження.
